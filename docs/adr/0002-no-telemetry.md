# No telemetry

Chrono collects no analytics, crash reports or usage data, and it declares "no data collected" on the Chrome Web Store and to Firefox (`data_collection_permissions: none`). We learn about breakage from two places instead: the help link, which pre-fills only the extension version, browser and OS, and the uninstall survey. "Something look wrong? Report it" is the same help link, sent only when the viewer clicks it, and it also names which of YouTube's players Chrono found (`player`), where the Panel sits (`layout`) and which parts of YouTube's page Chrono couldn't recognise (`failed`). It never carries anything that identifies the viewer or what they watch: no video IDs, titles or addresses. With a few hundred users, privacy and fast store reviews matter more than dashboards. Adding telemetry later would mean new store disclosures and Firefox consent prompts, so this should not be reversed casually.
