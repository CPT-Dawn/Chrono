# No telemetry

Chrono collects no analytics, crash reports or usage data, and it declares "no data collected" on the Chrome Web Store and to Firefox (`data_collection_permissions: none`). We learn about breakage from two places instead: the help link, which pre-fills only the extension version, browser and OS, and the uninstall survey. With a few hundred users, privacy and fast store reviews matter more than dashboards. Adding telemetry later would mean new store disclosures and Firefox consent prompts, so this should not be reversed casually.
