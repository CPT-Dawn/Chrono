## Agent skills

### Issue tracker

Issues live in GitHub Issues (CPT-Dawn/Chrono), via the `gh` CLI. See `docs/agents/issue-tracker.md`.

### Triage labels

Default vocabulary: `needs-triage`, `needs-info`, `ready-for-agent`, `ready-for-human`, `wontfix`. See `docs/agents/triage-labels.md`.

### Domain docs

Single-context: one `GLOSSARY.md` + `docs/adr/` at the repo root. See `docs/agents/domain.md`.

### Real-browser check

To verify a change on live YouTube in headless Chromium and Firefox, see `docs/agents/real-browser-check.md`.
